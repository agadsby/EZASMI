This directory contains the original [EZASMI Install.zip](https://groups.io/g/turnkey-mvs/attachment/901/0/EZASMI%2520Install.zip) as extracted from [Shelby Beach's post](https://groups.io/g/turnkey-mvs/topic/location_of_shelby_beach_s/81138288) on 3rd September 2026. 



The downloaded zip file was opened and the enclosed EZASMIInstall.jar was run to extract the contents as originally packaged by Shelby and Jürgen. These file were subsequently used to install the EZASMI system onto a running MVS3.8J tk5 system.
